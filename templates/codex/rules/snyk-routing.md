# Personal Snyk repository routing

Apply this section when the active repository's GitHub remote owner is `snyk`, regardless of local path:

- use `cli-technical-analysis` for technical analysis, investigation, and research
- use `cli-contributor` for code changes
- use `cli-branch-change-reviewer` for pull request, branch, and diff reviews
- use `cli-pr-comment-analysis` for unresolved pull request threads or comment analysis
- use both review skills when the request includes both code-diff review and pull request comment analysis
